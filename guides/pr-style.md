- **Title:** a Conventional Commit that names the area and says what the
  change does, lowercase after the colon, under 72 characters:
  `feat(webhooks): retry failed deliveries with backoff`.
- **Body:** a short paragraph on why: the problem, and who it affects.
  Then `## What changes`: bullets about behavior, not a list of files. Put
  code in code spans, and flag an API or schema change in bold. Then
  `## Testing`: the commands run and what they showed, with counts.
- Plain, short sentences. No first person, because the footer says who
  wrote it. No thanks, no emoji, no selling.
